# Ассеты: где брать

Держать **один стиль** — low-poly.

## 3D
- Unity Asset Store (фильтр Free) — https://assetstore.unity.com
- Quaternius (CC0, персонажи + анимации) — https://quaternius.com
- Kenney (CC0) — https://kenney.nl
- Poly Pizza (CC0 low-poly) — https://poly.pizza
- Poly Haven (CC0) — https://polyhaven.com
- Sketchfab (фильтр Downloadable, смотреть лицензию) — https://sketchfab.com
- Synty POLYGON (платно, часто в Humble Bundle) — City, Apartment

## Анимации
- Mixamo — https://www.mixamo.com

## Текстуры
- ambientCG (CC0) — https://ambientcg.com

## Звук и музыка
- Freesound — https://freesound.org
- Pixabay — https://pixabay.com/sound-effects/
- Sonniss GDC Bundle (бесплатно раз в год)
- Incompetech (CC-BY) — https://incompetech.com

## Лицензии
- CC0 — можно всё.
- CC-BY — указать автора в `assets-credits.md`.
- NC — **не брать**.
