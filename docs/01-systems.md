# Системы

Принцип: в Сезоне 0 собираем 5 систем, дальше сезоны только наполняют их контентом
(Ink, ScriptableObject). Новый код — только для уникальных мини-игр.

| # | Система | Что делает | Где используется | Нужно для Дня 1 |
|---|---|---|---|---|
| 1 | **Hub** | Квартира/район, игровой день, энергия, выбор дел | Везде | Да (базово: квартира, 1 день) |
| 2 | **Dialogue** | Диалоги и сюжет на Ink | Везде | Да |
| 3 | **Battle** | Батл подколов | Жена, реп-батлы, финальные боссы сезонов | Да (ссора с женой) |
| 4 | **Rhythm** | Нажимай в ритм | Балалайка, тренажерка, реп | Нет (День 2–3) |
| 5 | **Stream** | Экран стрима: чат, донаты, зрители, итог дня | Каждый вечер | Да (первый стрим) |

Плюс мини-игры: **Borsch** (День 1), Танчики, флешбек на бэхе и т.д.

## 1. Hub
- Вид от третьего лица или сверху (решить на прототипе).
- Интерактивные объекты: подойти → подсказка → действие (кровать, плита, комп, дверь).
- День: утро → дела → вечер (стрим) → итог → сон.
- Энергия: каждое дело тратит энергию.

## 2. Dialogue
- Ink. Один `.ink` файл на день сезона.
- Ink-теги для управления игрой: `# speaker: wife`, `# emotion: angry`,
  `# start_battle: wife_pot`, `# start_minigame: borsch`.
- Переменные Ink синхронизируются с показателями (настроение, отношения с женой).

## 3. Battle (батл подколов)
- Раунды: противник кидает подкол → игрок выбирает ответ из 3 вариантов.
- Ответы: **разнос** (сильный урон), **норм** (слабый), **кринж** (урон себе).
- Полоска «самоуважения» у обоих; у кого кончилась — проиграл.
- Тексты батла пишутся в Ink (узел `battle_<имя>`, stitch на раунд, подкол с тегом `# attack`,
  ответы с `#hit:strong|weak|cringe`), чтобы весь текст писался в одном месте.
  Пример: `battle_wife_pot` в `day01.ink`. Параметры (HP, урон) — в ScriptableObject.
- Чат стрима может реагировать на ответы (позже).

## 4. Rhythm
- Ноты летят по дорожкам, нажимай вовремя. Отложено до Дня 2.

## 5. Stream
- Экран компа: «трансляция», счётчик зрителей, чат.
- Чат: поток фраз из пула (мемы комьюнити) + реакции на события дня.
- Донаты с сообщениями; игрок выбирает реакцию.
- Итог стрима: зрители, деньги, настроение.
