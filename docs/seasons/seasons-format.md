# Формат сезонов 1+

Каждый сезон про **одного персонажа из комьюнити**.

Шаблон сезона:
1. **Появление** персонажа (тизер в конце прошлого сезона).
2. **Его история и мемы**: 2–4 игровых дня вокруг него.
3. **1–2 новые мини-игры** под его фишку.
4. **Финальный батл подколов** с ним (система Battle, новые данные).
5. **Тизер** следующего персонажа.

Новый сезон = новые Ink-файлы + новые данные батлов/чата + 1–2 мини-игры.
Системы не переписываем.
